# Resolume Arena Configurator 0.3.6

Configuration now requires the selected local PC Agent adapter to be up with the expected preferred address and prefix. The live Agent's schema, endpoint, adapter and network identity must match saved configuration. Server identity and job identity are checked again at mutation boundaries, preventing changed or replaced jobs from authorizing stale writes.

Remote Job Configurator servers and client-only installations remain supported. Readiness failures give actionable repair information, and unavailable downloads are gated without preventing offline LAN work with valid local components.

Validation: 36 regression/WPF checks and the isolated real server-to-Resolume HTTP identity/origin/replacement contract passed before release preparation.
