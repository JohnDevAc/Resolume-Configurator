# Resolume Arena Configurator 0.3.8

This release fixes all nine findings from the 12 September QA review. Automatic source matching rejects conflicting host/channel identities. Restart restoration pins the saved graph and rechecks group, layer and clip identities before writes, protecting against same-name compositions with different contents.

N6/N60 preset reuse now verifies the existing sender address and preserves foreign presets. Composition patches and process restarts revalidate the selected job and local Agent. Existing output preferences explicitly enable Advanced Output. Job Configurator integration schema 1 is required before changes.

The main window stays open during configuration, exclusive leases prevent overlapping operations, and helpers stop when their originating process exits. Concurrent preference edits are detected; atomic replacement backups stay beside their destinations and are referenced by the recovery record. Save verification supports coarse or unchanged timestamps and identical-content saves while rejecting stale unchanged files and preserving recovery copies on failure.

Validation: **55/55 application checks**, **5/5 packaging checks**, **8/8 independent HTTP contract checks**, and a Release build with zero warnings/errors. See `QA-REMEDIATION-2026-09-12.md` for finding-by-finding evidence and recovery details.

Compatibility remains Windows x64, Arena **7.27.x**, schema-1 Job Configurator/local PC Agent, and Kiloview **N6/N60**. PC NDI settings remain owned by PC Agent; no server/agent API changes are required. Physical Arena/NDI/device and physical FAT/SMB/second-volume acceptance remain outstanding. Packages are unsigned.
